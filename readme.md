 #  Floração – Clube de Assinatura de Flores

**Floração** é um site interativo que simula um clube de assinatura de flores.  
Todo mês, o usuário descobre quais flores estão em alta na estação, pode fazer um *quiz de estilo* para personalizar seus buquês e aprender mais sobre jardinagem urbana por meio de conteúdos educativos.

---

## 🚀 Tecnologias Utilizadas

| Camada | Tecnologias |
|--------|--------------|
| **Estrutura** | HTML5 |
| **Estilos** | CSS3 • Flexbox • Grid Layout |
| **Interatividade** | JavaScript (ES6+) |
| **Framework** | [Vue.js 3](https://vuejs.org/) (utilizado via CDN) |
| **Ferramentas de apoio** | VS Code • Git & GitHub |
| **Hospedagem** | GitHub Pages ou Netlify |

---

## 💡 Funcionalidades

### 🌼 Calendário das Flores
- Mostra, de forma visual e interativa, quais flores aparecem em cada mês.
- As flores mudam dinamicamente com base no mês selecionado.

### 🎨 Quiz de Estilo
- Perguntas sobre gostos pessoais e decoração.
- Mostra sugestões de buquês personalizados de acordo com o resultado.

### 🪴 Blog "Jardinagem Urbana"
- Seção de posts estáticos com dicas de cuidado e curiosidades sobre flores.
- Estrutura simples de HTML e JavaScript para navegação entre os artigos.
